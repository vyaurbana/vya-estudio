# VYA ESTUDIO

Actualizaciones de VYA ESTUDIO (VYA URBANA): descargas de vídeo y MP3, karaokes y vídeos profesionales.

Cada vez que se abre, el programa mira `version.json`; si hay una versión nueva, baja el zip, comprueba su huella (SHA-256) y se actualiza solo.
Aquí solo están los archivos del programa: nada de VYA ni contraseñas.

Publicar una versión: `python3 publicar.py <carpeta_del_programa> <numero>` y subir los cambios.
